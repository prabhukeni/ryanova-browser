# Ryanova Browser 1.1.0-beta.5

Privacy Shield preview: Strict protection is enabled by default. Click the shield beside the address bar to choose Strict, Balanced, or Standard for the active tab and view measured blocking activity. Use Menu → New Private Tab for an isolated temporary browsing session. Known trackers are blocked and common marketing tracking parameters are removed from navigated links.

Privacy Shield is experimental and is not a guarantee of anonymity. Strict protection can affect website functionality. The existing GitHub updater remains available for beta.4 → beta.5 testing.
